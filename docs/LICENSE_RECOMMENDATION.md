# License recommendation for the RSF-funded project

Decision, 2026-09-23: Apache-2.0 applied to original software following the
maintainer instruction to proceed with the recommendation. LICENSE contains the
unmodified official text. Funding: Russian Science Foundation, project 26-11-00193,
as supplied by the maintainer. No institution or copyright owner has been inferred.

Apache-2.0 permits reuse, modification and commercial redistribution and explicitly
addresses contributor patent grants, notices and changed files.
[Official license](https://www.apache.org/licenses/LICENSE-2.0).

MIT is a shorter permissive alternative but does not contain Apache's explicit
patent-grant provisions. [Official MIT text](https://opensource.org/license/mit).

RSF funding alone does not select an open-source license or establish that an
individual author may license all code. The actual competition and agreement matter:
for example, clause 33 of the 2025 small-group competition documentation assigns
rights to project performers, specifies a state-use nonexclusive-license mechanism,
and separately addresses cofinancing arrangements.
[Official competition document, clause 33](https://ias.rscf.ru/app/ext/user/conf/contests/docs/2025/118.pdf).

Grant administration information not supplied in this checkout:
- recipient organization;
- copyright holder(s), including employment or assignment arrangements;
- any cofinancing/industrial partner terms affecting publication and licensing;
- whether patent filing or restricted components are involved.

Do not label RSF as copyright owner merely because it funded the project.
Record funding acknowledgement separately using the actual grant number.
Limit the software license to original code; third-party datasets and dependencies
retain their own terms. Manuscript publication rights require separate treatment.

The specific grant agreement has not been provided or legally reviewed.
Applying the software license does not assert grant-specific legal clearance.
