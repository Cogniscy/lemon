# Claims and metrics audit

| Claim | Current evidence |
|---|---|
| Lexical factor coverage provides a weighted factor trace | Implemented; packaged demo exercises the real scorer |
| Lexical coverage reliably handles negation or participant binding | Not supported; two explicit known-limit examples and strict xfail tests |
| Perturbation proxy independently detects text errors | Not supported: factor_damage_proxy reads intended-damage metadata |
| Proxy ablation measures effects of the specified damage model | Supported by code; do not equate with validation of an inference system |
| Forward/reverse coverage describes full graph extraction quality | Not supported; reverse uses a lexical pseudo-extractor |
| The vector control is a dense embedding baseline | Only for an explicitly executed sentence-transformers backend |
| Expert agreement is reported in the manuscript | Reproduced from anonymized judgments and the included calculation script; ordinal alpha corrected to 0.873 |
| The full inventory has been expert validated | Not established by the pilot trace review |

## Vector-space perturbation baseline

The default hashed-char control is not a dense sentence embedding.
TF-IDF, hashed character counts and dense models have separate explicit backends.
Historical char_ngram_vector_cosine reports cannot uniquely identify their algorithm.
See [formats](REPORT_FORMATS.md).

## Expert review

`annotation/linguist_review_pack/expert_validation_form.xlsx` is a 50-row
inventory preparation pack. The paper describes a later 35-row trace review.
Do not use the former to substantiate the latter. The later review is available in
`annotation/expert_trace_review/`: 119/140 exact matches, ordinal alpha 0.873.
The previously reported 0.871 reproduces interval distances on ranks, not ordinal
marginal-frequency distances. Both calculations are recorded. These compare supplied
historical LEMON labels, not predictions freshly generated by the current scorer.

## Scope

The method assumes an explicit source graph and inventory. It does not establish
general text similarity, pragmatic understanding, global superiority over embeddings,
or reproduction of the original KGGen/MINE benchmark.

Historical wording and development notes are indexed under [archive](archive/README.md).
