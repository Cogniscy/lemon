\section{Experiments}
The experiments are designed as a sequence of checks on the same representation. We begin with WebNLG because its RDF-to-text setting makes graph--text alignment explicit. We then move to perturbation scoring across WebNLG, DrugProt, and BC5CDR to test whether the same factor format remains useful when predicates encode biomedical roles, direction, polarity, and causality. Deterministic scoring runs use JSONL inputs and fixed JSON factor inventories. LLM calls are isolated in the final reliability probe and are not used to construct the deterministic scores.

\subsection{Forward and reverse factor scoring}
The first WebNLG experiment scores development texts using predicate decompositions and lexical cues. We run an error-driven resource expansion: missing predicates are identified, deterministic decompositions are added, lexical cues are expanded, and coverage is recomputed. This separates missing evaluation resources from missing information in the text.

To test bidirectionality, we reconstruct a graph from each WebNLG text with a deterministic lexical pseudo-extractor and compute Reverse \lemonscore{}. The reverse score is compared with expanded Forward \lemonscore{}. A small forward--reverse gap would suggest that the same factor schema can support both KG$\rightarrow$Text coverage and Text$\rightarrow$KG recoverability.

\subsection{Node/edge retention and perturbations}
We compare Reverse \lemonscore{} with a \minebase{} baseline inspired by KGGen's Measure of Information in Nodes and Edges. The deterministic variant reports node information, edge information, and a composite node/edge score. A locked 50-fact subset is used to show how binary fact recoverability differs from a partial-credit node/edge composite. These values are diagnostic baselines, not a reproduction of the original KGGen/MINE benchmark.

Controlled perturbations are then injected into text and reconstructed graphs. The operators keep the source graph fixed and change only the text, which lets us ask whether a metric reacts to the intended semantic damage rather than to a change in the reference graph. The final scoring uses five operators: node deletion, relation-cue deletion, argument swap, polarity flip, and relation blur. Polarity flips are most informative for DrugProt and BC5CDR, where relation labels explicitly encode activation, inhibition, regulation, or causality.

We score the shared perturbation files with deterministic baselines: entity recall, label match, a binary triple-style match, a \minebase{} node/edge harmonic score, a label-only LEMON variant, and the full deterministic \lemonscore{} proxy based on the fixed factor inventories and perturbation metadata. The same scoring layer is used for the compact ablation study.

\subsection{Exploratory LLM factor judging}
The LLM reliability probe asks a different question: whether model judges can still recover the same factors after deterministic perturbations mark them as damaged. We sample perturbed instances from WebNLG, DrugProt, and BC5CDR and ask three independent LLM judges to label each semantic factor as covered, partially covered, or absent. The judges are Gemini 2.0 Flash, GPT-4o-mini, and Llama-3.1-70B. The prompts use JSON-schema constrained outputs through OpenRouter. The probe is reported as diagnostic evidence, not as human validation.
