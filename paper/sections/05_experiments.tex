
\section{Experiments}
The experiments test one representation from several angles. WebNLG provides an explicit RDF-to-text setting. DrugProt and BC5CDR then test whether the same factor format remains meaningful when predicates encode biomedical roles, direction, polarity, and causality. Deterministic scoring uses JSONL inputs and fixed JSON factor inventories. LLM calls appear only in the final reliability probe; they are not used to construct the deterministic scores.

\subsection{Forward and reverse factor scoring}
The first WebNLG experiment scores development texts using predicate decompositions and lexical cues. We run an error-driven resource expansion: missing predicates are identified, deterministic decompositions are added, lexical cues are expanded, and coverage is recomputed. This separates missing evaluation resources from missing information in the text.

To test bidirectionality, we reconstruct a graph from each WebNLG text with a deterministic lexical pseudo-extractor and compute Reverse \lemonscore{}. The reverse score is compared with expanded Forward \lemonscore{}. A small forward--reverse gap would indicate that the same factor schema can support both KG$\rightarrow$Text coverage and Text$\rightarrow$KG recoverability.

\subsection{Node/edge retention and perturbations}
We compare Reverse \lemonscore{} with a \minebase{} baseline inspired by KGGen's Measure of Information in Nodes and Edges. The deterministic variant reports node information, edge information, and a composite node/edge score. A locked 50-fact subset shows how binary fact recoverability differs from a partial-credit node/edge composite. These values are diagnostic baselines, not a reproduction of the original KGGen/MINE benchmark.

Controlled perturbations are then injected into text and reconstructed graphs. The operators keep the source graph fixed and change only the text, which lets us ask whether a metric reacts to intended semantic damage rather than to a change in the reference graph. The final scoring uses five operators: node deletion, relation-cue deletion, argument swap, polarity flip, and relation blur. Polarity flips are most informative for DrugProt and BC5CDR, where relation labels explicitly encode activation, inhibition, regulation, or causality.

We score the shared perturbation files with deterministic baselines: entity recall, label match, a binary triple-style match, a \minebase{} node/edge harmonic score, a label-only LEMON variant, and a factor damage proxy based on the fixed factor inventories and intended-damage metadata. The proxy does not infer damage from text. Its ablation study measures the response of this specified damage model. An offline character n-gram vector baseline is reported as a lexical/topical control, not as a dense embedding benchmark.

\subsection{Pilot expert trace review}
To test whether LEMON's factor traces match human judgments, we prepared a compact expert review form with eight diagnostic graph--text examples and 35 factor rows. Four completed expert submissions were included. Reviewers assigned each factor one of the same ordinal preservation labels used by LEMON: preserved, mostly preserved, partial, mostly lost, lost, or contradicted. We then measured exact and weighted LEMON--expert agreement, chance-corrected agreement, and inter-expert reliability. Ordinal Krippendorff alpha uses marginal-frequency distances over the declared six-category order; equally spaced rank distances give the distinct interval coefficient (0.871). Anonymized judgments and the calculation script are included in the repository. Agreement compares the LEMON labels supplied in the historical forms, without rerunning the current scorer.

\subsection{Exploratory LLM factor judging}
The LLM reliability probe asks a different question: whether model judges can still recover the same factors after deterministic perturbations mark them as damaged. We sample perturbed instances from WebNLG, DrugProt, and BC5CDR and ask three independent LLM judges to label each semantic factor as covered, partially covered, or absent. The judges are Gemini 2.0 Flash, GPT-4o-mini, and Llama-3.1-70B. The prompts use JSON-schema constrained outputs through OpenRouter. The probe is reported as complementary diagnostic evidence.
