\section{Experiments}
The experiments follow the six research questions as a single evaluation path. We first establish whether predicate-factor coverage adds information beyond lexical overlap, then test whether the same representation can be used in reverse, and finally stress the metrics with controlled perturbations across general-domain and biomedical data. Deterministic scoring runs use JSONL inputs and fixed JSON factor inventories. No LLM calls are made in the deterministic perturbation scoring reported in RQ5; LLM judging is isolated in RQ6.

\subsection{RQ1: Forward factor-level semantic coverage}
We first score WebNLG development texts using predicate decompositions and lexical cues. We then run an error-driven resource expansion: missing predicates are identified, rule-based or fallback decompositions are added, lexical cues are expanded, and coverage is recomputed. This measures how much of the initial low score comes from missing resources rather than from the text itself.

\subsection{RQ2: Bidirectional factor recoverability}
To test whether the factor representation is bidirectional, we reconstruct a graph from each WebNLG text with a deterministic lexical pseudo-extractor and compute Reverse \lemonscore{}. This score is compared with expanded Forward \lemonscore{}. A small forward--reverse gap suggests that the same factor schema can support both KG$\rightarrow$Text coverage and Text$\rightarrow$KG recoverability.

\subsection{RQ3: MINE-style node/edge information retention}
We compare Reverse \lemonscore{} with a \minebase{} baseline inspired by KGGen's Measure of Information in Nodes and Edges. The deterministic variant reports node information, edge information, and a composite node/edge score. A previously locked 50-fact subset is also used to show how binary fact recoverability differs from a partial-credit node/edge composite. These values are reported as diagnostic baselines, not as a reproduction of the KGGen/MINE benchmark.

\subsection{RQ4: Controlled perturbation calibration}
We inject deterministic noise into text and reconstructed graphs. Destructive perturbations should reduce relevant scores; preserving perturbations should produce smaller changes. Text-side perturbations are used primarily to calibrate Forward \lemonscore{}, while graph-side perturbations are used primarily to calibrate Reverse \lemonscore{} and MINE-style recoverability.

\subsection{RQ5: Cross-domain deterministic baseline scoring}
The final perturbation files cover WebNLG, DrugProt, and BC5CDR. The operators keep the source graph fixed and change only the text, which lets us test whether a metric reacts to the intended semantic damage rather than to a change in the reference graph. The final scoring uses five operators: node deletion, relation-cue deletion, argument swap, polarity flip, and relation blur. Polarity flips are most informative for DrugProt and BC5CDR, where relation labels explicitly encode activation, inhibition, regulation, or causality.

We score the shared perturbation files with deterministic baselines. The goal is not to reproduce external systems such as FactSpotter or KGGen/MINE, but to provide local comparison points with the same inputs. We report entity recall, label match, a binary triple-style match, a \minebase{} node/edge harmonic score, a label-only LEMON variant, and the full deterministic \lemonscore{} proxy based on the fixed factor inventories and perturbation metadata. The same scoring layer is used for the compact ablation study.

\subsection{RQ6: Exploratory LLM factor judging}
To test whether deterministic perturbation labels agree with model-based semantic recovery, we run a small LLM reliability probe. We sample perturbed instances from WebNLG, DrugProt, and BC5CDR and ask three independent LLM judges to label each semantic factor as covered, partially covered, or absent. The judges are Gemini 2.0 Flash, GPT-4o-mini, and Llama-3.1-70B. The prompts use JSON-schema constrained outputs through OpenRouter. The probe is reported as diagnostic evidence, not as human validation.
