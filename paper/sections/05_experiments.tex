\section{Experiments}
\subsection{Experiment 1: initial factor coverage}
The first experiment scores the WebNLG development set using the synthetic adjudicated predicate decomposition dictionary and the seed lexical cue dictionary. We report five quantities: exact entity-label coverage, predicate lexical cue coverage, weighted \lemonscore{} coverage, missing decomposition rate, and the number of low-coverage edges under a threshold of 0.5.

\subsection{Experiment 2: error-driven expansion}
The initial run exposes predicates without decompositions. We therefore run a missing-predicate analysis, generate rule-based or fallback decompositions for the missing predicates, extend the lexical cue dictionary, and recompute coverage. This experiment tests whether \lemonscore{} can be improved through interpretable error-driven resource expansion.

\subsection{Experiment 3: lexical baseline comparison}
The third experiment compares \lemonscore{} to lightweight lexical controls. Exact entity-label overlap checks whether entity labels are mentioned. Predicate cue coverage checks explicit relation cues. Graph--text token Jaccard and graph--text token cosine compare a bag-of-words graph lexicalization with the text. These controls are not intended as strong semantic metrics; they make explicit whether \lemonscore{} adds a diagnostic dimension beyond surface overlap.


\subsection{Experiment 4: bidirectional text--graph recoverability}
The fourth experiment evaluates the reverse direction. We construct a deterministic reconstructed graph from each WebNLG text using entity-label evidence and predicate lexical cues. We then score this reconstructed graph in two ways. First, reverse \lemonscore{} checks whether the recovered graph retains the weighted predicate factors of the gold graph. Second, a MINE-style node/edge baseline adapts the Measure of Information in Nodes and Edges idea to WebNLG: gold triples are treated as facts, reconstructed graphs are treated as extracted KGs, and information retention is measured through recovered nodes and edges. This experiment has two MINE-style variants: a deterministic node/edge-hit baseline and an optional LLM-judged recoverability baseline. In the LLM-judged variant, the judge receives a gold fact and a retrieved subgraph and decides whether the fact is inferable without outside knowledge.
