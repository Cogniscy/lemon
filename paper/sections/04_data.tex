\section{Data and Experimental Resources}
\subsection{WebNLG pilot}
The experiments use a stratified English WebNLG pilot. The train split contains 200 examples and the development split contains 100 examples. Both splits cover 16 WebNLG categories. The development set contains 308 graph edges. The pilot is intentionally small: it is designed to validate the scoring pipeline and to make error analysis inspectable before scaling to larger WebNLG subsets or domain-specific graphs.

\subsection{Synthetic predicate decompositions}
A seed factor inventory was built from train predicates and categories. LLM-assisted candidate generation was then tested with two models. The LLM stage is model-agnostic: all models receive the same factor schema, prompt template, and JSON output constraints. In the sanity run, the two models achieved similar factor F1 against the rule-based seed reference, while role accuracy remained lower, indicating that role assignment is the main unstable part of the task.

A synthetic adjudicator was then applied to 29 predicates. The synthetic reference had LLM candidate coverage of 0.621: 18 predicates had LLM candidates and 11 predicates did not. The mean adjudicator confidence was 0.830. This resource is useful for development, but it is not a substitute for human expert annotation.
