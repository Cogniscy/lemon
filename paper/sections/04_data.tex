\section{Data}

We use a stratified WebNLG pilot because the dataset provides explicit RDF triples paired with verbalizations. The current pilot contains 200 train examples and 100 development examples sampled across 16 categories. Train data is used to build the factor inventory and decomposition resources; development data is used to measure graph--text coverage. The main coverage experiment scores 100 development examples containing 308 edges.

The WebNLG pilot is intentionally small. Its role is to validate the pipeline and produce interpretable diagnostics before moving to larger WebNLG subsets or domain-specific datasets.
