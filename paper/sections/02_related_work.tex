\section{Related Work}
\subsection{RDF-to-text evaluation and reference metrics}
The WebNLG Challenge made Resource Description Framework (RDF)-to-text generation a standard test bed: systems receive DBpedia-derived triples and produce natural-language verbalizations \cite{gardent2017webnlg}. WebNLG+ later added bilingual and bidirectional settings, so the same data family can support graph-to-text generation and text-to-graph recovery \cite{castroferreira2020webnlg}. GEM placed such tasks within a broader natural language generation (NLG) evaluation suite, and recent LLM-based graph-to-text work, such as PlanGTG, revisits planning and attribution in graph-conditioned generation \cite{gehrmann2021gem,he2025plangtg}.

These benchmarks often report sentence-level reference metrics. BLEU measures word n-gram precision; METEOR aligns words, stems, and synonyms while balancing precision and recall; chrF++ uses character n-gram F-score with a word n-gram extension; TER counts edits needed to transform an output into a reference \cite{papineni2002bleu,banerjee2005meteor,popovic2017chrf,snover2006ter}. BERTScore compares contextual token embeddings, and BLEURT learns a reference-based quality signal from human-rated examples \cite{zhang2020bertscore,sellam2020bleurt}. These metrics are useful for reference similarity and generation quality. They do not identify whether a source predicate preserved its argument roles, direction, polarity, or evidence.

\subsection{Source-aware factuality and graph metrics}
Source-aware metrics move closer to the input structure. PARENT weights n-gram precision and recall by evidence in the source table and reference text; Data-QuestEval casts data-to-text coverage as question answering; AlignScore learns a general alignment function for factual consistency \cite{dhingra2019parent,rebuffel2021dataquesteval,zha2023alignscore}. FactSpotter is the closest prior graph-to-text evaluation approach: it checks whether a triple \((s,p,o)\) is present in a generated text and correlates with human judgments of correctness, coverage, and relevance \cite{zhang2023factspotter}. LEMON differs by replacing a binary whole-triple decision with weighted predicate-factor diagnosis.

Text-driven factuality metrics take the opposite route. They decompose generated text into verifiable claims and check support against evidence, as in FActScore and VERISCORE \cite{min2023factscore,sun2024veriscore}. Semantic graph metrics compare structures under node alignment, as in Smatch, S$^2$match, and Smatch++ for Abstract Meaning Representation (AMR) parsing \cite{cai2013smatch,opitz2020s2match,opitz2023smatchpp}. LEMON is source-driven: it decomposes the graph predicate first and evaluates the text against that decomposition.

\subsection{MINE-style recovery and LLM judging}
Text-to-knowledge-graph (text-to-KG) evaluation asks whether extracted graphs retain information from text. KGGen introduces a language-model-based extractor and MINE, the Measure of Information in Nodes and Edges, for node and edge retention \cite{mo2025kggen}. Our MINE-style baseline adapts this node/edge split to WebNLG graph--text pairs. It is a useful coarse graph-fidelity signal, but it does not separate polarity errors, role swaps, and missing relation class; all can appear as edge-level failure.

LLM-based evaluation can recover meaning that lexical rules miss, but it must be separated from reproducible scoring. G-Eval and MT-Bench illustrate both the scale of LLM judging and its calibration risks \cite{liu2023geval,zheng2023mtbench}. We use LLMs only in an exploratory factor-judging probe; the main tables are rule-based and reproducible without API calls.

\subsection{Behavioral metric calibration}
A metric should react predictably to controlled changes. CheckList introduced invariance and directional tests for NLP models \cite{ribeiro2020checklist}. Perturbation CheckLists and synthetic stress tests apply the same idea to NLG evaluation \cite{sai2021perturbation,he2023blindspots}. Our perturbations follow this logic: relation deletion, argument swap, polarity flip, and relation blur test whether a metric reacts to intended semantic damage.
