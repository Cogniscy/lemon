\section{Method}
\subsection{Problem setting}
Let a graph--text pair be \((G,T)\), where \(G\) is a set of directed edges \(e=(s,p,o)\) and \(T\) is a verbalization. The forward task asks whether the text covers the information in the graph. The reverse task asks whether a graph reconstructed from the text, denoted \(\hat{G}(T)\), preserves the information in the original graph. \lemonscore{} uses the same predicate-level semantic representation in both directions.

\subsection{Predicate factorization}
Each predicate \(p\) is mapped to a weighted decomposition:
\[
D(p)=\{(f_i,r_i,w_i)\}_{i=1}^{n},
\]
where \(f_i\) is a semantic factor, \(r_i\) is its role, and \(w_i>0\) is a salience weight. Roles cover predicate meaning, subject and object domains, value domains, and modifiers such as direction, polarity, causality, or evidence. The representation is coarser than a full ontology but richer than a single predicate label. A text that keeps both entities but loses the relation cue should therefore receive partial credit rather than full coverage.

\subsection{Factor inventory construction and weights}
The inventories are fixed before scoring. They are manually specified diagnostic resources built from predicate labels, argument roles, domain constraints, entity types, and lexical evidence cues. Weights are normalized salience priors: predicate-meaning factors usually receive the largest share; domain factors and modifiers receive smaller shares when they are part of the predicate meaning. These weights are auditable design choices, not learned parameters or expert-certified semantic constants; expert validation is prepared but not yet reported.

Figure~\ref{fig:predicate-factor-eval} shows two worked examples using current inventory weights. The point is not that \lemonscore{} is always numerically higher than a coarse node/edge score, but that a coarse relation mismatch can be decomposed into different semantic causes.

\subsection{Forward LEMON: KG$\rightarrow$Text coverage}
For an edge \(e\), text \(T\), and component \((f_i,r_i,w_i)\), an evidence function \(E(f_i,r_i,e,T)\in[0,1]\) estimates whether the component is expressed. In the deterministic implementation, entity and domain factors are supported by normalized label or token evidence, while relation factors are supported by predicate cues and factor cues. The edge-level forward score is:
\[
S_F(e,T)=\frac{\sum_i w_i E(f_i,r_i,e,T)}{\sum_i w_i}.
\]
Example-level and corpus-level scores are averages over edges with available decompositions. The implementation stores covered and missing factors for each edge, so the scalar score is accompanied by a diagnostic trace.

\subsection{Reverse LEMON: Text$\rightarrow$KG recoverability}
The reverse direction first constructs a deterministic reconstructed graph \(\hat{G}(T)\) from the text using entity-label evidence and predicate lexical cues. Reverse \lemonscore{} then compares each gold edge with its best recovered counterpart. Subject and object recovery contribute through node/domain evidence; predicate recovery contributes through overlap between the gold predicate's factors and the recovered edge evidence. The reverse score therefore asks whether the source predicate's semantic factors survive the text-to-graph reconstruction.

The current reconstructed graph is a lexical pseudo-extractor, not a full KG extraction model. This choice makes the experiment reproducible and keeps the focus on metric behavior rather than extractor quality. Future work can replace \(\hat{G}(T)\) with KGGen, GraphRAG-style extraction, OpenIE, or domain-specific extractors.

\subsection{MINE-style node/edge baseline}
To compare factor-level recoverability with node/edge information retention, we implement a \minebase{} baseline inspired by KGGen's MINE. Each gold triple is treated as a fact, and the reconstructed graph is searched for matching or related nodes and edges. The deterministic score separates node information, edge information, and a composite partial-credit node/edge score. We report it as a local baseline rather than a reproduction of the original benchmark.

\subsection{Controlled perturbation calibration}
A metric that measures semantic alignment should degrade under meaning-destroying perturbations and remain comparatively stable under meaning-preserving perturbations. We therefore create deterministic perturbations of both text and reconstructed graphs. Text-side destructive perturbations include relation phrase deletion, object swaps, and predicate swaps. Graph-side destructive perturbations include node drops, edge drops, and predicate swaps. Preserving perturbations include alias-like rewrites and template paraphrases, which are flagged as clean or weak-template depending on their reliability. All perturbed files and operation-level manifests are saved, enabling audit of each injected change.
