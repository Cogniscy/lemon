\section{Introduction}
Knowledge graphs encode information as typed relations between entities. In RDF-style graph-to-text generation, an input edge \((s,p,o)\) is not only a pair of entity names. The predicate \(p\) states which relation holds, which semantic roles the arguments fill, and which part of the meaning must be preserved in text. The same issue appears in the reverse direction. If a text is converted back into a graph, a useful reconstructed edge must preserve relation meaning, not merely mention the same entities.

This distinction is often hidden by holistic automatic metrics. A sentence may mention \textit{Alan Bean} and \textit{Wheeler, Texas} while omitting that the relation is \textit{birthPlace}. In biomedical text, the same chemical and protein can be present while the polarity changes from inhibition to activation. Standard WebNLG evaluation uses reference metrics such as BLEU, METEOR, chrF++, TER, BERTScore, and BLEURT, together with human criteria such as data coverage, relevance, correctness, and fluency \cite{gardent2017webnlg,castroferreira2020webnlg,gehrmann2021gem}. These criteria are useful, but they do not say which internal semantic component of a predicate is covered or missing.

We propose \lemonscore{}, a source-driven diagnostic framework for graph--text semantic alignment. The core idea is to decompose each source predicate into typed, weighted semantic factors. For example, \textit{birthPlace} can be represented by a person-like subject factor, a biographical-relation factor, and a place-like object factor. A DrugProt inhibition predicate can be represented by a chemical actor, a gene/protein target, negative regulation, directionality, and evidence form. \lemonscore{} then checks whether these factors are expressed in text or recovered in a reconstructed graph. This creates a diagnostic layer between binary triple-level metrics, such as FactSpotter, and text-driven atomic-fact metrics, such as FActScore \cite{zhang2023factspotter,min2023factscore}.

The framework is bidirectional. In the forward direction, KG$\rightarrow$Text, it measures whether a text covers the semantic factors of the input graph. In the reverse direction, Text$\rightarrow$KG, it measures whether a reconstructed graph preserves the semantic factors of the source graph. We also implement a \minebase{} node/edge baseline inspired by KGGen's Measure of Information in Nodes and Edges (MINE), which evaluates text-to-KG information retention through recovered nodes and relations \cite{mo2025kggen}. The baseline is used as a transparent comparison point; it is not a reproduction of the full KGGen/MINE benchmark.

The paper asks six research questions. \textbf{RQ1:} Does factor-level coverage capture graph-to-text semantic preservation beyond entity-label overlap? \textbf{RQ2:} Does the same factor representation support both forward coverage and reverse recoverability? \textbf{RQ3:} How does factor-level recoverability relate to node/edge information retention in a MINE-style baseline? \textbf{RQ4:} Do the metrics behave predictably under meaning-destroying and meaning-preserving perturbations? \textbf{RQ5:} Does the same deterministic factor format produce useful perturbation diagnostics on biomedical graph--text data? \textbf{RQ6:} How do independent LLM factor judges compare with deterministic perturbation labels?

The contributions are: (1) a bidirectional, weighted factor-level formulation for graph--text semantic alignment; (2) a reproducible WebNLG pilot with forward and reverse factor scores; (3) fixed factor inventories for WebNLG, DrugProt, and BC5CDR; (4) a MINE-style node/edge information baseline adapted to graph--text pairs; (5) controlled perturbation scoring showing that relation-level damage is not captured by entity preservation alone; and (6) an exploratory three-judge LLM reliability probe. The study is deliberately framed as a diagnostic pilot. Factor decompositions are deterministic resources supported by rules and schema constraints, and LLM judgments are treated as diagnostic evidence rather than human-validated gold.
