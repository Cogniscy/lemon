# LEM-01 Result Contract

This file fixes the minimum evidence package for the final paper. A result can enter the paper only if it is generated by code or backed by a saved report.

## Required tables

| Table | Purpose | Required before submission |
|---|---|---|
| Dataset overview | Shows WebNLG, DrugProt, and BC5CDR scope | Yes |
| Method/baseline positioning | Compares LEMON-Factor with entity overlap, triple checks, and MINE-style recall | Yes |
| WebNLG final results | Main graph-to-text pilot results | Yes |
| Biomedical transfer results | DrugProt + BC5CDR second-domain evidence | Yes |
| Perturbation calibration | Shows response to node/edge/relation damage | Yes |
| Ablation study | Shows contribution of factor groups and weights | Yes |
| Multi-model reliability | Replaces unsupported human-validation claims with synthetic reliability evidence | Yes, at least on a subset |

## Required figures

| Figure | Purpose | Status |
|---|---|---|
| Figure 1A: predicate-factor decomposition | Explains that a predicate is a bundle of factors | Required |
| Figure 1B: bidirectional evaluation | Explains forward and reverse use of the same factors | Required |

The two panels should be combined into one figure if page budget is tight.

## Baseline contract

| Baseline | WebNLG | DrugProt | BC5CDR | Wording |
|---|---:|---:|---:|---|
| Entity overlap | Required | Required | Required | entity baseline |
| Binary triple or relation check | Required | Required | Required | binary relation baseline |
| FactSpotter-style check | Required if feasible | Optional | Optional | style baseline unless official implementation is used |
| MINE-style node/edge recall | Required | Optional | Optional | MINE-style or MINE-inspired |
| LEMON-Factor full | Required | Required | Required | proposed diagnostic framework |

## Minimal submission fallback

If the full plan cannot be completed, the paper remains defensible only if the following are present:

1. WebNLG final results.
2. At least one biomedical transfer table using DrugProt or BC5CDR.
3. Entity overlap and binary relation baselines.
4. Ablation table.
5. Clear limitation statement on LLM adjudication.

Without biomedical evidence, the paper should be submitted only as a WebNLG pilot and all cross-domain claims must be removed.
