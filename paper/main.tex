\begin{abstract}
Graph--text evaluation requires more than checking whether the right entity names occur in a fluent sentence. A faithful verbalization must preserve the roles and relation meanings encoded by graph predicates, and a useful text-to-graph reconstruction must recover the same predicate-level information. We propose \lemonscore{}, a bidirectional factor-level diagnostic framework for graph--text pairs. \lemonscore{} decomposes relation predicates into weighted semantic factors and evaluates both KG$\rightarrow$Text coverage and Text$\rightarrow$KG recoverability. The framework is positioned between triple-level factuality metrics, which typically issue one decision per triple, and atomic-fact metrics, which decompose generated text rather than source predicates. On a stratified WebNLG pilot, expanded Forward \lemonscore{} reaches 0.7915 and Reverse \lemonscore{} reaches 0.7789. A \minebase{} adaptation inspired by KGGen's Measure of Information in Nodes and Edges shows that node information is easier to recover than edge information: on a locked 50-fact subset, deterministic node information is 0.9600 and edge information is 0.5400. Controlled perturbation calibration shows that relation deletion reduces Forward \lemonscore{} by 0.211 while exact entity-label coverage changes by only 0.002. We further instantiate the same factor inventory format for DrugProt and BC5CDR and score controlled biomedical perturbations. The results support \lemonscore{} as an interpretable pilot framework for diagnosing relation-level semantic alignment. We treat rule-based factor inventories and synthetic LLM adjudication resources as provisional, not as human expert validation.
\keywords{Graph-to-text evaluation \and Semantic alignment \and Knowledge graphs \and WebNLG \and Biomedical relation extraction \and Predicate decomposition}
\end{abstract}
