\title{LEMON-Factor: Interpretable Factor-Level Semantic Coverage for Graph--Text Evaluation}
\author{Anonymous}
\institute{Anonymous}
\maketitle
\begin{abstract}
Graph-to-text systems should preserve the meaning of each input relation, not only mention the correct entities or produce a fluent sentence. Existing automatic metrics for RDF-to-text generation are either reference-based and holistic, or operate at the level of whole triples. We propose LEMON-Factor, a diagnostic evaluation framework that decomposes source predicates into weighted semantic factors and checks how these factors are reflected in a verbalization. The current pilot builds a unified WebNLG graph--text dataset, derives a predicate inventory, creates synthetic LLM-adjudicated predicate decompositions, and evaluates deterministic factor-level coverage on a stratified WebNLG development subset. Error-driven expansion reduces missing predicate decompositions and raises factor-level coverage while preserving edge-level audit trails. The pilot is intended as a reproducible proof of concept; synthetic adjudication is not treated as human expert validation.
\keywords{Graph-to-text evaluation \and Semantic coverage \and Knowledge graphs \and WebNLG \and Predicate decomposition}
\end{abstract}
